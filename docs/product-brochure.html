CORE FEATURES

핵심 기능

스마트팜 운영에 필요한 모든 기능을 통합 제공합니다

📊

실시간 대시보드

온도, 습도, CO2 등 센서 데이터를 실시간 게이지와 차트로 시각화. 다중 하우스를 한눈에 모니터링할 수 있습니다.

실시간 게이지 다중 하우스 트렌드 분석
🎛️

원격 장치 제어

창문, 환풍기, 관수밸브, 히터 등 19종 이상의 장치를 웹/모바일에서 원격 제어. Modbus RTU 릴레이를 통한 하드웨어 직접 제어를 지원합니다.

19+ 장치 유형 Modbus RTU 수동/자동 모드
🤖

자동화 엔진

센서 기반 조건 + 시간 스케줄 조합으로 복합 자동화 규칙 설정. 쿨다운, 우선순위, 지속시간 제어까지 지원합니다.

센서 조건 시간 스케줄 AND/OR 로직
🧠

AI 농업 어시스턴트

Google Gemini (클라우드) + Ollama (로컬) 이중 AI로 병충해 진단, 생육 예측, 작업 추천. 카메라와 음성입력도 지원합니다.

병충해 진단 Gemini 무료 카메라/음성
📝

영농일지

파종부터 수확까지 모든 농작업을 기록. 사진 첨부, 수확/자재 이력 관리, 캘린더 뷰, PDF/CSV 내보내기를 제공합니다.

사진 5장 수확/자재 기록 PDF 내보내기
📄

보고서 & 분석

일간/주간/월간 리포트 자동 생성. 센서 통계, 제어 빈도, 자동화 실행 이력을 한눈에 파악할 수 있습니다.

일/주/월 리포트 시각화 차트 Excel 내보내기
🔔

알림 & 경보

센서 임계값 초과, 장비 이상, 유지보수 일정 등을 실시간 알림. 위험도별(긴급/경고/정보) 분류 및 확인 추적 기능을 제공합니다.

실시간 알림 위험도 분류 이력 관리
🔐

사용자 & 권한 관리

4단계 역할 기반 접근 제어(RBAC). 최고관리자, 관리직원, 농장대표, 작업자별 기능 접근을 세밀하게 관리합니다.

4단계 RBAC 다중 농장 JWT 인증

DEPLOYMENT

유연한 배포 모드

환경에 맞는 최적의 운영 방식을 선택할 수 있습니다

☁️

클라우드 모드

AWS 인프라를 활용한 완전한 클라우드 운영. 다중 농장 관리, 어디서든 접속, 자동 확장을 지원합니다.

🔄

하이브리드 모드

클라우드 + 로컬 이중 운영. 인터넷 장애 시 자동 폴백, 복구 시 자동 동기화. 무중단 운영을 보장합니다.

🏠

팜로컬 모드

인터넷 없이 100% 로컬 운영. RPi에서 직접 제어, 센서 수집, AI 분석까지. 완전한 오프라인 독립 운영이 가능합니다.
