# 양액 자동 시스템 BOM — 운영급 + 알파

> **목표 정밀도**: EC ±0.05 mS/cm (운영급) · pH ±0.02 (Atlas EZO 알파)
> **예상 총액**: 약 ₩165~175만원
> **적용 농장**: farm_0001 (RPi 1호, 192.168.219.111) — 1차 검증 후 표준 이미지 v5_3 에 통합
> **버전**: 2026-05-16 작성

## 시스템 개요

```
RPi 1호 ─ USB-485 (CH340, /dev/smartfarm-485) ─ RS-485 단일 버스
   │       ├── Unit-Id 1 — XY-MD02 온습도 (기존)
   │       ├── Unit-Id 2 — Waveshare 8CH 릴레이 (기존, 환기·차광)
   │       ├── Unit-Id 3 — 신규 24CH Modbus 릴레이 (양액 전용)
   │       │     ├ CH 0~5 : 도싱 펌프 A·B·C·D·산·알칼리
   │       │     ├ CH 6   : 메인 송수 펌프
   │       │     ├ CH 7   : 교반기
   │       │     ├ CH 8~21: 관수 밸브 1~14
   │       │     ├ CH 22  : 원수 보충 솔레노이드
   │       │     └ CH 23  : 예비
   │       └── Unit-Id 4 — Modbus EC 트랜스미터 (신규)
   │
   ├── USB ─ Atlas EZO-pH Carrier Board (정밀 알파) ─ pH 프로브 (방수)
   │
   └── GPIO ─ 비상정지 버튼 (BCM 17, 풀업)
              누액 감지 센서 (BCM 27)
              플로트 스위치 ×7 (BCM 22~28)
```

## Phase 3.2 — 하드웨어 도착 후 작업

### 1차 (센서 도착) 시
1. RS-485 신규 부품 Unit-Id 변경
   - EC 트랜스미터: 기본 1 → **4** (mbpoll 명령)
   - Atlas EZO 는 USB 라 Unit-Id 무관
2. Node-RED 양액 자동제어 탭
   - `🧪 시뮬레이터 ON` inject 클릭 해제 (또는 `🧪 시뮬레이터 OFF` 클릭)
   - Modbus Read 노드 (Unit-Id 4) → 안전 인터락 연결
   - Serial in 노드 (`/dev/ttyACM0`) → Atlas EZO 파싱 → 안전 인터락
3. **EC 보정** — 1.413 mS/cm KCl 표준액에 5분 침지 후 frontend NutrientSettings → 센서 보정 → EC 재보정
4. **pH 보정** — 4.01 / 6.86 / 9.18 완충액 3-포인트 보정

### 2차 (도싱 펌프 + 24CH 릴레이) 시
1. 24CH 릴레이 Unit-Id **3** 으로 설정 (mbpoll)
2. 도싱 펌프 채널 0~5 와이어 연결 (펌프 + 24V 전원 + 릴레이)
3. **펌프 캘리브레이션**:
   - 펌프 ON 60초 → 수집 mL 측정 → 분당 mL 계산
   - frontend NutrientSettings → 하드웨어 → dosingPulseUnit 값 입력
4. 안전 인터락 출력 2 → 24CH 릴레이 와이어 연결 (비상 OFF)
5. cycle-runner 출력 0 → 24CH 릴레이 와이어 연결

### 3차 (관수 회로) 시
1. 솔레노이드 ×14 와이어 (채널 8~21)
2. 메인 펌프 (채널 6), 교반기 (채널 7)
3. 시뮬 모드로 1회 사이클 풀 동작 → 실 모드 전환

### 4차 (안전·박스) 시
1. 비상정지 버튼 GPIO 17 + Node-RED rpi-gpio in 노드 추가
2. 누액 센서 GPIO 27 + 같은 패턴
3. 컨트롤 박스 내부 배선 정리 + IP54 차폐

### 5차 (현장) 시
- 농장 배치
- 시운전
- v5_3 표준 이미지에 양액 탭 통합
