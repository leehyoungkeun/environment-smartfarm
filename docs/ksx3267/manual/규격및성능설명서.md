# 규격 및 성능설명서 — 스마트그린 통합제어기 (KS X 3267 / KOAT 116·117)

버전 0.1 초안 (2026-09-02). KOAT 검정기준 116/117 「통합제어기」 §1「규격 및 성능설명서」 양식에 대응.
`〔 〕` = **시험 전용 기체 확정 후 케이그린텍이 실측·기입**할 항목(제조국·모델·치수 등 조달/실물 정보). 나머지는 실제 시스템 사양 기준.

## 1. 규격 및 성능설명서

### 가. 형식명 / 제조사 / 제조국
- 형식명: 〔모델명 기입 — 예: SmartGreen IC-1〕
- 제조사: 케이그린텍
- 제조국: 대한민국

### 나. 형식
- 온실 통합제어기 (마스터). RS-485 Modbus RTU, KS X 3267:2022 디폴트 레지스터맵·레벨 1 지원.

### 다. 기체의 크기 (본체 컨트롤박스, 케이스 기준)
- 길이(mm): 〔실측 기입〕
- 폭(mm): 〔실측 기입〕
- 높이(mm): 〔실측 기입〕

### 라. 기체의 규격
**1) 통합제어기 (본체)**
- 가) OS: Raspberry Pi OS (Debian) 64-bit 〔버전 기입 — 예: Debian 12/13〕
- 나) Processor
  - (1) 제조사 / 제조국: Broadcom / 〔기입〕 (SoC BCM2712)
  - (2) 모델명: Arm Cortex-A76 쿼드코어 2.4 GHz (Broadcom BCM2712)
- 다) MainBoard
  - (1) 제조사 / 제조국: Raspberry Pi Ltd / 영국(UK)
  - (2) 모델명: Raspberry Pi 5 〔8GB 여부 기입〕
- 라) RAM
  - (1) 제조사 / 제조국: 〔기입〕 (보드 온보드 LPDDR4X)
  - (2) 모델명: LPDDR4X
  - (3) 개수: 온보드 8 GB 1식 〔확정 기입〕
- 마) GraphicsCard: 해당 없음 (SoC 내장 VideoCore VII)
- 바) Storage
  - (1) 제조사 / 제조국: 〔기입〕
  - (2) 모델명: 〔기입 — microSD 또는 NVMe SSD 용량〕
- 사) POWER
  - (1) 제조사 / 제조국: 〔기입〕
  - (2) 모델명: 〔기입 — 예: 공식 27W USB-C PD 어댑터〕
- 아) Database: 로컬 SQLite(제어기 내장, 60일 보관) + 클라우드 PostgreSQL 17 + TimescaleDB(영구 보관·조회·추출)
- (관제 클라이언트) 웹(Web) ○ / 모바일 앱(App) Android ○ · iOS ○ (PWA)

**2) 기타 (RS-485 인터페이스)**
- 가) 제조사 / 제조국: 〔기입 — USB-RS485 절연 컨버터〕
- 나) 모델명: 〔기입〕. 표준 노드 전용 포트 `/dev/smartfarm-485-std` (9600 8N1). 자체 장치용 포트 `/dev/smartfarm-485` 별도.

### 마. 기체의 관제 방식
**1) 관제(모니터링 및 제어) 지원 여부**: 본체(컨트롤박스) ○ · 모니터 패널(현장 키오스크) ○ · 기타(웹/모바일 PWA) ○

**2) 통합제어기 관제 방식**: ☑ **복합형**
- 노드(센서&구동기) ↔ (RS-485 Modbus RTU) ↔ 통합제어기(로컬) ↔ (HTTPS/MQTT) ↔ 클라우드(로컬서버 겸용)
- 로컬서버(제어기 자체 REST) 로 인터넷 단절 시에도 현장 관제(팜로컬) 지속, 정상 시 클라우드 동기화.

### 사. 연동 장비
**1) 센서** — 연동 KS X 3267 `○`
- KS X 3267 표준 센서 노드(디폴트맵, 30채널): 온도·습도·CO₂ 등. 연동 KS X 3267 ○
- (표준 미적용, 연동 별도 인정 ○) XY-MD02 온습도 — RS-485 Modbus RTU FC04

**2) 구동기** — 연동 KS X 3267 `○`
- KS X 3267 표준 구동기 노드(디폴트맵, 레벨 1): 스위치 16 + 개폐기 8. 연동 KS X 3267 ○
- (표준 미적용, 연동 별도 인정 ○) Waveshare 8CH 릴레이 — RS-485 Modbus RTU FC01/FC15

> 연동장비표의 최종 ○/× 범위(표준 명시 기종 전부 vs 실제 연동분)는 **시험기관 확인 1순위 항목**.

## 2. 성능 (KOAT 116 성능시험 기준 대응)

| 116 성능 기준 | 본 제어기 구현 | 근거 |
|---|---|---|
| 센서 상태정보 데이터 **손실률 3 % 이내** | 1분 주기 수집, 결측은 빈 칸(미조작·미보고 구분), 로컬 SQLite 버퍼 + 재전송 | actuator/센서 파이프라인 |
| 구동기 상태정보 **손실률 3 % 이내** | 표준 구동기 1분 스냅샷(변화 없어도 하트비트 기록), 3분 무응답 시 손실로 명시(값 미조작) | `actuator_status` 1분 버킷 |
| 2항목 이상 **시각화 1시간 이하 단위 + 1·7·30일** | 대시보드 차트: 1시간·6시간·24시간·7일·30일(30일=1시간 단위) | SensorChart |
| **조회 1분 단위 + 1·7·30일** (일부/전체 항목) | 보고서 › 데이터 조회·추출: 센서/제어이력/표준구동기, 1분 행 표, 기간·항목 선택 | DataExplorer |
| **추출 .csv/.txt/.xls** (1분 단위, 1·7·30일) | 서버 CSV/TXT(원본), 클라이언트 XLSX. 결측 빈 칸 | `/api/.../export` |
| 종료/**전원 차단·인가 후 데이터 복구** | 재기동 시 드라이버·화면 자동 복귀, 데이터는 로컬 SQLite·클라우드에 유지 → 조회·추출 가능 | pm2 resurrect + 영구 저장 |
| 제어(구동기 명령·상태 readback) | 표준 노드 OPID 명령·상태 폴링(2초)·1분 스냅샷, 상태코드·남은시간 표시 | ks3267 드라이버 |

**프로토콜 적합성 (SPS X KOAT-0004-7466 §5.4/5.5)**: 디폴트맵·레벨1·프로토콜버전 10 기준 자가시험 표4 시나리오 7/7 통과(증적 `docs/ksx3267/self-test/`). 본시험은 시험기관 시험장비(노드) 지참으로 진행.

**소프트웨어 구성**: Node-RED(오케스트레이터) + ks3267 드라이버 데몬(pymodbus, 표준 노드 전용 포트) + 백엔드(Express, PostgreSQL/TimescaleDB) + 프론트(React PWA·현장 키오스크). 자체 장치와 표준 노드는 이중 드라이버로 공존.
