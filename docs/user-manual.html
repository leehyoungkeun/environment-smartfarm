2. 작동 원리

비닐하우스나 온실의 환경을 자동으로 조절해주는 장치입니다. 컴퓨터나 스마트팜 태블릿을 통해서 원격에서 제어가 가능하고, 센서가 측정한 값에 따라 기계가 알아서 작동하도록 해줍니다.

  • 실시간 측정 (내부) — 온도, 습도, CO₂ 농도, 일사량, 토양 수분, EC/PH
  • 실시간 측정 (외부) — 강우, 풍속, 외부 온도
  • 자동 제어 — 측정값에 따라 천창·측창·펌프·환기팬 등을 알아서 동작
  • 원격 모니터링 — 인터넷이 되는 곳이라면 스마트폰·PC로 어디서든 확인·제어
추가 가능한 센서는 국가스마트팜표준인 RS-485 Modbus를 지원하는 제품에 한하여 추가 가능합니다.
표준 미지원 센서(아날로그·1-Wire 전용 등)는 별도의 변환 모듈 없이는 등록할 수 없습니다. 새 센서 도입 전 반드시 케이그린텍에 호환 여부를 확인해 주세요.
본 제어기는 장비를 직접 제어하지 않습니다.
MARO-FARM26은 RS-485 Modbus 명령으로 릴레이 모듈의 마그네트(전자접점)를 ON/OFF 시켜 현장 장비의 전원을 제어하는 방식입니다.
· 제어기 → Modbus 명령 → 릴레이 모듈 마그네트 동작 → 장비 전원선 ON/OFF
· 모터·펌프·조명 등 실제 장비의 동작·역회전·속도 조절은 현장 마그네트·인버터·컨트롤박스가 담당합니다.
따라서 장비별 정·역회전 결선·과부하 보호·열보호는 설치 시 현장 전기·기계 설비에서 처리되어야 하며, 본 제어기 설정에서는 ON/OFF 신호 채널만 지정합니다.

1.4 화면 둘러보기

역할보이는 메뉴

2. 대시보드 보기

대시보드는 농장의 현재 상태를 한눈에 보는 화면입니다. 화면 위쪽 ‘대시보드’ 메뉴를 누르면 나옵니다.

2.1 위쪽 하우스 선택

여러 하우스(동)이 있는 경우, 파란 띠 안의 ‘1번 하우스 / 2번 하우스 …’ 탭에서 보고 싶은 하우스를 누르세요. 탭 옆의 작은 숫자는 그 하우스에서 발생한 알림 개수입니다.

2.2 위젯 종류

위젯의미
오늘의 요약데이터 수집 건수, 전체 알림 수, 심각·경고 알림 수 — 정상이면 ‘오늘은 이상 없이 정상 운영 중’이 표시됩니다.
시스템 상태센서 상태(정상/경고), 활성 센서 개수, 미확인 알림, 수집 주기(예: 60초)
센서 게이지현재 센서 값. 색이 초록이면 정상, 노랑은 주의, 빨강은 위험
센서 차트지난 24시간 동안의 변화 그래프
대시보드 오른쪽 위 ‘로컬 전환’ 버튼은 인터넷이 끊겼을 때 농장 내부 RPi로 직접 접속하는 모드입니다. 평소에는 누를 필요가 없습니다.

2.3 게이지 색상의 의미

🟢초록: 정상 범위 — 아무 조치도 필요 없음
🟡노랑: 경계 — 주의 깊게 보세요
🔴빨강: 위험 — 즉시 확인이 필요합니다 (알림이 함께 옵니다)
센서 값이 회색으로 보이거나 ‘--’ 로 나오면 일시적으로 데이터가 안 들어오는 상태입니다. 1~2분 기다려도 그대로면 7장 ‘알림 처리’를 참고하세요.

3. 장치 제어

창문, 펌프, 팬, 조명 같은 장치를 직접 켜고 끌 수 있습니다.

3.1 제어 화면 들어가기

1위쪽 메뉴에서 제어를 누릅니다.
2제어할 하우스 탭을 선택합니다.
3장치 카드에서 명령 버튼을 누릅니다.

3.2 위쪽 3개 버튼

버튼의미
⏹ 비상정지현재 동작 중인 모든 장치를 즉시 멈춥니다. 위급 상황에만 사용.
▶ 자동화자동화 규칙이 동작 중임을 표시. 누르면 잠시 끄고 켤 수 있습니다.
‖ 수동모드자동화를 잠시 멈추고 수동으로만 조작하고 싶을 때.

3.3 장치별 명령

장치 종류명령
1창·측창·천창·차광·스크린·관수밸브▲ 열기 / ■ 정지 / ▼ 닫기 — 양방향 동작
펌프·모터·조명·팬·온풍기·냉방기·CO₂공급기● ON / ○ OFF

각 장치 카드 오른쪽 위의 ‘수동’ / ‘대기’ 표시는 현재 그 장치가 자동화 대상인지 사람이 조작 중인지를 알려줍니다.

3.4 자동 정지 (창문류)

측창을 ‘▲ 열기’로 누르면 설정해 둔 시간(예: 15초)만큼만 동작하고 자동으로 정지합니다. 그 사이에도 다시 누르면 즉시 멈춥니다. 카드 가운데의 ‘0%’ 표시는 현재 몇 % 열려 있는지 보여줍니다.

창문이 끝까지 열리는 시간은 농장마다 다릅니다. 설정 → 하우스/센서 에서 장치별로 동작 시간을 미리 등록해 두면 매번 보정할 필요가 없습니다.

3.5 진행 막대 자동 복원

창문이 동작 중일 때 페이지를 잠시 떠났다가 돌아와도, 경과 시간이 자동 계산되어 진행 막대가 이어서 보여집니다.

3.5 인터넷이 끊긴 경우

외부 인터넷이 끊겨도 같은 와이파이에 있으면 농장 내부에서 직접 제어할 수 있습니다. 화면이 ‘팜로컬 모드’로 바뀌고 제어가 정상 동작합니다.

외부 인터넷도 끊기고 농장 와이파이도 안 잡히는 경우에만 제어가 안 됩니다. 이때는 케이그린텍에 연락 주세요 (12장 연락처 참고).

4. 자동화 규칙

‘아침 7시에 측창 열기’, ‘온도가 30℃를 넘으면 측창 열기’ 같은 동작을 자동으로 하게 만들 수 있습니다.

4.1 규칙 만들기 농장대표 전용

1위쪽 메뉴에서 설정을 누릅니다.
2‘🤖 자동화규칙’ 탭을 누릅니다.
3적용할 하우스 탭을 선택합니다.
4왼쪽에서 규칙 종류 ‘🌡 센서 기반’ 또는 ‘⏰ 시간대별’ 또는 ‘사용자 정의’ 를 선택합니다.
5오른쪽 ‘+ 새 규칙’ 버튼을 누르고 조건·동작을 설정한 뒤 저장합니다.
화면 예시 — “20도 이하 문닫기” 규칙: 온도 < 20 이면 측창 1을 15초간 닫고, 5분간 쿨다운. 규칙 카드 오른쪽 위 초록 토글로 잠시 끄고 켤 수 있습니다.

4.2 조건의 종류

조건예시
센서 기반온도가 30°C 초과, 습도가 60% 미만
시간대별매일 06:30~07:00, 월·수·금만
사용자 정의‘오후 1~5시 사이’에 ‘온도 28°C 초과’이면 (시간 + 센서 복합)

4.3 동작의 종류

장치 제어가 가능한 모든 명령(열기/정지/닫기, 켜기/끄기)을 동작으로 지정할 수 있습니다. 한 규칙에서 여러 장치를 동시에 제어할 수도 있습니다.

4.4 우선순위와 쿨다운

설정의미
우선순위여러 규칙이 동시에 맞으면 우선순위가 높은 규칙이 먼저 실행
쿨다운(초)규칙이 한 번 실행된 후 다시 실행되기까지 기다리는 시간 (기본 300초 = 5분)
센서가 임계값 근처에서 흔들릴 때 자동화가 너무 자주 켜졌다 꺼지지 않도록 쿨다운을 충분히(5~15분) 잡는 것이 좋습니다.

4.5 규칙 켜기/끄기·수정·삭제

규칙 카드 오른쪽 위의 초록 토글로 잠시 멈출 수 있습니다. ‘수정’ 버튼으로 조건·동작을 바꾸고, ‘삭제’ 버튼으로 영구 제거할 수 있습니다. 계절성 규칙은 삭제하지 말고 토글로만 끄시면 다음 시즌에 다시 켤 수 있어 편합니다.

4.6 자동화 규칙 세부 화면

4.6.1 자동화 규칙 메인

등록된 규칙 목록 화면입니다. 카드별로 조건·동작·다음 실행 시간이 표시되며, 우상단 토글로 임시 비활성화 가능합니다.

4.6.2 센서 기반 규칙 만들기

센서 값(온도·습도·CO₂ 등)이 임계값을 넘거나 떨어질 때 자동 동작합니다.

설정 완료 후 규칙 카드:

4.6.3 시간 기반 규칙 만들기

매일 같은 시각에 동작합니다 (예: 06:30 측창 열기, 18:00 차광 닫기). 자정을 넘기는 구간(22:00~04:00)도 지원합니다.

설정 완료 후 규칙 카드:

4.6.4 사용자 정의 (시간 + 센서 복합)

특정 시간대에만 센서 조건을 적용합니다. 예: 오후 1~5시 사이에 온도 28°C 초과이면 천창 열기. 시간이 게이트 역할을 해서 야간엔 동작 안 함.

시간 게이트 + 센서 조건은 가장 실용적인 패턴입니다. ‘낮에만 환기’, ‘밤에만 보온’ 등.

7. 알림 처리

종류의미대처
센서 임계값 초과온도·습도 등이 위험 범위제어 페이지에서 환기·차광 조작 또는 자동화 확인
오프라인 감지농장 RPi가 5분 이상 데이터 안 보냄현장 인터넷·전원 확인. 12장 연락처 참고

3알림 체크 간격 (1·3·5·10분) 과 중복 알림 방지(쿨다운) (5·15·30분·1시간) 을 조정합니다.

근본적으로는 자동화 규칙으로 환기·차광이 자동 동작하게 만들면 위험 상황 자체가 줄어 알림도 줄어듭니다.

7.5 알림 설정 세부 화면

7.5.1 일반 알림 설정

알림 종류·체크 간격·쿨다운·심각도 임계값을 조정합니다.

7.5.2 오프라인 알람

RPi가 일정 시간(기본 5분) 이상 서버에 데이터를 안 보낼 때 발생합니다. 현장 인터넷·전원 확인 신호.

7.5.3 서버 연결 경고

RPi와 케이그린텍 서버 사이 통신이 일시적으로 끊겼을 때 알림. 자동 복구되면 해제됩니다.

7.5.4 장비 고장 알람

같은 장치 명령이 반복 실패하면 ‘고장 의심’으로 분류해 알림. 워치독이 자가 진단합니다.

7.5.5 센서 임계값 알람

센서 종류별로 정상 범위를 벗어나면 알림. 임계값은 센서 등록 시 자동 설정되며 여기서 조정 가능합니다.

9. 설정 농장대표 전용

이 장은 농장대표 권한이 있어야 보입니다. 작업자는 이 메뉴가 보이지 않습니다.

설정 화면은 5개 탭으로 나뉩니다 — 🏠 하우스/센서 / 📷 카메라 / 🤖 자동화규칙 / 🔔 알림설정 / ⚙ 시스템. 이 장에서는 ‘하우스/센서’ 탭을 자세히 다룹니다 (자동화는 4장, 알림설정은 7.4 참고).

9.1 하우스 기본 설정

5‘+ 작물 추가’ 로 재배 중인 작물을 등록합니다.

9.2 센서 추가

추가 가능한 센서는 국가스마트팜표준인 RS-485 Modbus를 지원하는 제품에 한하여 추가 가능합니다.
표준 미지원 센서(아날로그·1-Wire 전용 등)는 별도의 변환 모듈 없이는 등록할 수 없습니다. 새 센서 도입 전 반드시 케이그린텍에 호환 여부를 확인해 주세요.
1하우스 상세 화면을 아래로 내려 ‘🌡 센서’ 영역을 찾습니다.
2아이콘 카드에서 종류를 고릅니다 — 온도, 습도, CO₂, 환기, 일사량, 조도, 외부온도/습도, 풍향/풍속, 강우감지, 토양수분, 토양EC/PH, 양액EC/PH, 유량계, 수위센서, 기타.
3센서 ID, 이름, 단위, 아이콘, 최소값/최대값 을 입력합니다 (정상 범위로 사용).
4아래 초록색 ‘🌡 센서 추가’ 버튼을 누릅니다.
5등록된 센서는 아래 목록에 보입니다 (예: temp_0001 · °C · 범위 -10~50).
센서 옆 U1:R1 Q1[0] (FC3) +10 같은 표기는 Modbus 통신 주소입니다. 새 센서를 직접 등록하실 때는 케이그린텍이 알려드린 번호를 그대로 입력하세요.

9.2.1 설정 관리 메인 화면

설정 메뉴의 첫 화면입니다. 좌측 탭에서 농장·센서·제어장치·카메라를 선택할 수 있습니다.

9.2.2 센서 추가 — 종류 선택

아이콘 카드에서 등록할 센서 종류를 누릅니다. 이미 추가된 센서는 우상단에 ‘추가됨’ 배지가 표시됩니다.

9.2.3 습도 센서 등록 예시

‘습도’ 카드를 누르면 자동으로 센서 ID(예: humid_0001)가 채워집니다. 이름·단위·범위 확인 후 ‘+ 센서 추가’.

9.2.4 온도 센서 등록 예시

온도 센서는 보통 -10 ~ 50°C 범위로 자동 설정됩니다. 정상 범위를 벗어나면 알림이 발생합니다.

9.3 제어 장치(개폐기·펌프) 등록

본 제어기는 장비를 직접 제어하지 않습니다.
MARO-FARM26은 RS-485 Modbus 명령으로 릴레이 모듈의 마그네트(전자접점)를 ON/OFF 시켜 현장 장비의 전원을 제어하는 방식입니다.
· 제어기 → Modbus 명령 → 릴레이 모듈 마그네트 동작 → 장비 전원선 ON/OFF
· 모터·펌프·조명 등 실제 장비의 동작·역회전·속도 조절은 현장 마그네트·인버터·컨트롤박스가 담당합니다.
따라서 장비별 정·역회전 결선·과부하 보호·열보호는 설치 시 현장 전기·기계 설비에서 처리되어야 하며, 본 제어기 설정에서는 ON/OFF 신호 채널만 지정합니다.
1하우스 상세 화면을 더 내려 ‘🎛 제어 장치’ 영역으로 갑니다.
2아이콘 카드에서 종류를 고릅니다 — 1창, 측창, 천창, 차광, 스크린, 펌프, 모터, 조명, 순환팬, 양액공급, 배양액, 조명제어, 무인방제기, 온풍기, 냉방기, CO2공급기, 분무제어, 관수밸브, 기타.
3장치 유형 과 장치 이름 을 입력합니다 (예: ‘측창 1’).
4아래 초록색 ‘+ 추가’ 버튼을 누릅니다.
5등록된 장치 행 오른쪽의 ▼ 화살표를 누르면 Modbus 채널·동작 시간을 추가 설정할 수 있습니다.
릴레이 번호(예: U1:CH2+3, U2:CH0)와 모듈 종류는 잘못 입력하면 다른 장치가 동작합니다. 처음 등록할 때는 반드시 케이그린텍 기술자와 함께 진행하세요.

10. 사용자 관리 농장대표 전용

작업자 계정을 추가·삭제하고 비밀번호를 바꿉니다.

10.1 사용자 관리 화면 들어가기

위쪽 메뉴 끝의 ‘👤 관리자’ 버튼을 누르면 사용자 관리 화면이 열립니다. 화면 위쪽에 역할별 인원 수 (최고관리자·관리직원·농장대표·작업자) 가 카드로 보입니다.

10.2 작업자 추가

1오른쪽 위 ‘+ 사용자 추가’ 를 누릅니다.
2아이디·이름·임시 비밀번호를 정합니다.
3역할은 ‘작업자’ 를 선택합니다 (다른 농장대표를 추가하려면 ‘농장대표’).
4접근 가능한 하우스를 체크합니다 (전체 또는 일부).
5저장하면 목록 맨 아래에 추가됩니다.

10.3 사용자 검색·필터

검색창에서 아이디·이름으로 찾을 수 있고, 역할 / 상태(활성·비활성) / 소속농장 별로 거를 수도 있습니다.

10.4 비밀번호 변경

본인 비밀번호: 위쪽 메뉴 ‘관리자’ → 본인 행의 ✏ 수정 아이콘.

다른 사용자 비밀번호: 사용자 목록에서 해당 행의 ✏ 수정 → ‘비밀번호 재설정’.

비활성화: 같은 행의 토글로 잠시 로그인 차단 (퇴사·휴직 시).

11. 자주 묻는 질문 (FAQ)

Q1. 화면이 하얗게 나오고 안 떠요

① 화면을 새로고침합니다 (브라우저 위쪽 ↻ 버튼 또는 F5).
② 그래도 안 되면 인터넷 연결을 확인합니다.
③ ‘화면 표시 오류’ 박스가 보이면 ‘새로고침’ 버튼을 눌러주세요.

Q2. 비밀번호를 잊어버렸어요

같은 농장의 농장대표에게 ‘사용자 관리 → 비밀번호 재설정’을 요청하세요. 농장대표 본인 비밀번호를 잊은 경우는 케이그린텍에 연락 주세요.

Q3. 센서 값이 ‘--’ 로만 보여요

① 1~2분 기다려 보세요 — 일시적인 현상일 수 있습니다.
② 5분 이상 그대로면 오프라인 알림이 옵니다.
③ 농장 인터넷 공유기와 RPi(까만 박스)의 전원이 켜져 있는지 확인하세요.
④ 그래도 복구가 안 되면 12장 연락처로 문의하세요.

Q4. 제어 버튼을 눌러도 장치가 안 움직여요

① 위쪽 메뉴 ‘알림’ 버튼에 ‘오프라인’ 알림이 있는지 확인합니다.
② 같은 와이파이에 있다면 ‘팜로컬 모드’로 자동 전환되어 동작합니다.
③ 외부 인터넷·내부 와이파이 둘 다 끊긴 경우는 케이그린텍에 연락 주세요.
④ 다른 사용자가 동시에 같은 장치를 조작하면 마지막 명령만 적용됩니다.

Q5. 자동화 규칙이 작동을 안 해요

① 규칙 옆 토글이 켜짐(파란색)인지 확인합니다.
② 시간 조건은 RPi의 시간을 기준으로 합니다 — 농장 시간대 확인.
③ 쿨다운 시간 안에 있으면 다음 실행까지 기다려야 합니다.
④ 설정을 바꾼 뒤 ‘자동화 적용’ 버튼을 눌렀는지 확인합니다.

Q6. 사진을 올렸는데 위치가 안 찍혔어요

스마트폰 브라우저에서 위치 권한이 차단되어 있을 가능성이 큽니다.
① 크롬: 주소창 왼쪽 자물쇠 → ‘사이트 설정’ → ‘위치’ 허용
② 사파리: 설정 → 사파리 → ‘위치’ → 허용

Q7. 알림이 너무 많이 와요

설정 → 알림 설정에서 임계값을 조정하거나, 자주 발생하는 항목의 쿨다운을 늘려 주세요. 근본적으로는 자동화 규칙으로 환기·차광이 자동 동작하게 만들면 알림이 줄어듭니다.

Q8. 농장이 여러 곳인데 한 화면에서 보고 싶어요

화면 위쪽 ‘농장관리’ 또는 ‘농장 선택’ 드롭다운에서 농장을 전환할 수 있습니다. 한 화면에 여러 농장 비교 기능은 관리직원·최고관리자 권한에서만 제공됩니다.

Q9. 인터넷이 자주 끊기는데 데이터가 사라지나요?

아닙니다. 농장 RPi가 데이터를 자체 저장하고, 인터넷이 복구되면 자동으로 서버에 보냅니다. 영농일지·수확 기록은 작성 즉시 서버에 저장되므로 인터넷 연결이 필요합니다.

Q10. 화면이 작아서 글씨가 잘 안 보여요

브라우저에서 Ctrl + + 를 눌러 확대하세요. 스마트폰은 두 손가락으로 벌리면 확대됩니다.
