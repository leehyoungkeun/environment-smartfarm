# KS X 3267 실제 노드 시험 절차서

스마트그린 통합제어기(RPi 1호) · 2026-09-17 시험용 · 작성 2026-09-16

이 문서는 시뮬레이터가 아닌 **실제 KS X 3267 노드**를 제어기에 연결해 SPS-X KOAT-0004-7466 §5.4 / §5.5 절차를 화면으로 밟고 증적을 남기는 순서입니다. 한 사람이 키오스크 앞에서 그대로 따라가면 됩니다.

## 1. 시작 전 준비물

| 구분 | 준비물 | 확인 |
|---|---|---|
| 노드 | KS X 3267 디폴트 레지스터맵 노드(센서 또는 구동기), 노드 주소(슬레이브 ID) 메모 | ☐ |
| 전원 | 노드용 24 VDC 전원(PSU), 제어기 5 V 어댑터 | ☐ |
| 배선 | RS485 2가닥(A/B) + GND 1가닥, 120 Ω 종단저항 2개(양 끝) | ☐ |
| 제어기 | 표준 노드용 USB-RS485 변환기(**FTDI**, 포트 이름 `/dev/smartfarm-485-std`) — 자체 장치용 CH340 변환기와 다른 것 | ☐ |
| 인터넷 | 휴대폰 핫스팟 또는 시험 장소 Wi-Fi(비밀번호) — **제어기 전원을 켜기 전에** 준비 | ☐ |
| 기록 | 카메라(화면 캡처), 이 절차서 | ☐ |

주의: 제어기에는 시계 배터리가 없어 전원을 켤 때 1970년으로 시작하고 인터넷이 잡혀야 시각이 맞습니다. **인터넷이 준비된 뒤 전원을 켜세요.** 저장 시각이 틀리면 §5.4.4 저장 증적을 못 씁니다.

## 2. 배선 (KS X 3267 표 1)

| 노드 M12 4핀 | 선 색 | 신호 | 제어기 쪽 |
|---|---|---|---|
| 1 | 적 | 전원 + (24 VDC) | 24 V PSU + |
| 2 | 녹 | RS485-A | FTDI 변환기 A |
| 3 | 백 | RS485-B | FTDI 변환기 B |
| 4 | 흑 | 전원 − / GND | 24 V PSU − 와 FTDI GND 를 **한 점에 공통** |

- A↔A, B↔B 를 바꾸지 마세요. 바꾸면 연결 시험 d) 만 실패합니다.
- 종단저항 120 Ω 은 버스 물리 양 끝 두 곳(제어기 쪽 1개, 마지막 노드 1개)에만.
- **CH340 변환기(`/dev/smartfarm-485`)에는 절대 연결하지 않습니다.** 그 버스에 우리 릴레이·온습도계가 붙어 있습니다.
- 통신 규격: RTU 9600 bps, 8N1. 노드 주소 1~247.

## 3. 시험 순서

각 단계에서 「캡처」 표시가 있는 화면을 사진으로 남깁니다.

### 3.1 제어기 켜기와 상태 확인
1. 인터넷 준비 → 제어기 전원 ON → 키오스크 로그인.
2. **설정 › 표준노드** 탭 → ① 「드라이버 연결 상태」 가 **연결됨**, 포트가 `tcp 127.0.0.1:5020`(시뮬레이터) 인지 확인.
3. 화면 위 시각이 현재 시각인지 확인(시계 동기).

### 3.2 §5.4.1 연결 시험
1. 노드 배선을 마치고 24 V 를 켭니다.
2. ① 「통신 설정」 → **「시험 당일 값으로」** 버튼(연결 방식 RS485 · 표준 노드 포트 · 9600 이 채워짐) → **적용** → 경고 창 확인 → 오른쪽 위 「포트 열림」.
3. 「§5.4.1 연결 시험」 → 노드 슬레이브 아이디 입력 → **▶ 연결 시험 실행** → a)~d) 네 줄이 모두 「일치」. **캡처.**
4. 주소를 모르면 ② 「B. 범위 자동 스캔」(1~16, 300 ms) 으로 먼저 찾습니다. 여러 노드를 붙일 때는 한 대씩 연결해 주소를 확인합니다(같은 주소 2대는 둘 다 안 잡힙니다).
5. 배선 중 생긴 「예외·타임아웃」 숫자는 ① 줄의 **「통계 초기화」** 로 0 으로 되돌립니다.

### 3.3 §5.4.2 / §5.5.1 노드 검색 시험
1. ② 「A. 주소 하나 탐색」 에 노드 주소 → **탐색**.
2. ③ 「찾은 노드」 카드에서 확인 후 **캡처**:
   - 「노드 기본정보 시험표」 — 기관코드 0, 회사코드 0, 제품타입 1(센서)/2(구동기), 제품코드 0, 프로토콜버전 10, 채널수 30/24 → **전 항목 일치**
   - 「연결된 디바이스」 — 머리에 개수·종류 요약(예: `온도 3 · 습도 1 · CO2 1`, `스위치 16 · 개폐기 8`)이 노드 사양과 같은지. 「코드 불일치」 배지가 뜨면 그 노드의 맵이 표준 위치와 다른 것 — 그대로 기록.
3. 카드 머리가 「디폴트맵 · 레벨1」 이 아니라 「스코프 밖」 이면 그 노드는 우리 인증 범위(디폴트맵·레벨1·프로토콜버전 10) 밖입니다. 화면을 캡처하고 노드 사양을 확인합니다.

### 3.4 §5.1.3 / §5.4.3 데이터 읽기·확인 (센서 노드)
1. 같은 카드의 「노드 데이터 읽기 시험표」 — 상태코드 0(정상)과 관측치·단위가 읽히고 **전 항목 적절**. **캡처.**
2. 「§5.4.3 데이터 확인 — 관측 변화 이력」 — 센서를 손으로 감싸거나 바람을 불어 값을 바꾸고, 표에 값 변화가 시각과 함께 쌓이는지 확인. 노드가 상태코드를 바꿀 수 있으면(점검 필요 등) 상태 변화도 같은 표에 나옵니다. **캡처.**
3. 「범위 밖 의심」 은 참고 경고이며 판정을 바꾸지 않습니다.

### 3.5 §5.4.4 데이터 저장 (센서 노드, 10분 이상)
1. 3.4 를 이어서 하며 10분 이상 둡니다.
2. 카드의 「§5.4.4 데이터 저장 확인」(서버) 과 「제어기 로컬 저장 (SQLite)」 두 표가 모두 **저장주기대로**, 저장 행 = 기대 행, 빈틈 0 인지 확인. **캡처.** 인터넷이 없으면 로컬 저장 표만 봅니다.
3. **보고서 › 데이터 조회·추출 › 「표준 센서 관측치·상태 (KS X 3267)」** 에서 그 10분을 조회하고 csv 추출. **캡처.**

### 3.6 §5.5.2 레벨 1 스위치 제어 (구동기 노드)
전제: 3번 하우스의 「온풍기 1」 이 **노드 1 스위치 1** 로 매핑돼 있습니다. 실제 노드 주소나 스위치 번호가 다르면 **설정 › 하우스/센서 › 3번 하우스 › 온풍기 1** 에서 노드 주소(unit)·번호(n)를 먼저 맞춥니다.
1. **환경제어 › 3번 하우스 › 온풍기 1** 카드 → **📐 시간 지정 ON** → 초 입력(예: 20) → 실행.
2. 노드가 켜졌는지(표시등·릴레이 소리) 확인 — c).
3. 카드 배지 「켜짐 NN s」 가 줄어드는지 — e), f). 동시에 표준노드 탭 §5.1.3 표의 스위치 행: 상태코드 **201**, OPID, 「남은 NN s」 카운트다운. **둘 다 캡처.**
4. 카드 **OFF** → 노드가 꺼지는지 — h), i). 배지·표가 **READY(0)** 로. **캡처.**
5. ④ 「진단」 을 열어 프레임(FC16 503~506 쓰기, FC03 203~206 읽기 hex)도 한 장 **캡처.**

### 3.7 §5.5.3 레벨 1 개폐기 제어 (구동기 노드)
전제: 「측창 1」 이 **노드 1 개폐기 1** 로 매핑, 완전 개폐 시간 30 s 로 설정돼 있습니다(다르면 하우스/센서 탭에서 수정).
1. **측창 1** 카드 → 「📐 작동시간」 초 입력(예: 20) → **⏱ 시간 열기** → 노드가 여는지 확인 → 배지 「열리는 중 NN s」 감소 + §5.1.3 표 상태코드 **301**. **캡처.**
2. **■ 정지** → 노드 정지 → **READY**. **캡처.**
3. **⏱ 시간 닫기** → 「닫히는 중 NN s」 + 상태코드 **302**. **캡처.** → **■ 정지** → READY. **캡처.**
4. 일반 ▲열기/▼닫기(301/302) 도 한 번씩 눌러 노드가 움직이는지 확인합니다.

### 3.8 116 구동기 상태 저장 (구동기 노드)
1. 3.6~3.7 뒤 몇 분 두고, 표준노드 탭 구동기 카드의 「116 구동기 상태 1분 저장 — 제어기 로컬」 표에 스위치·개폐기 행이 1분마다 쌓이는지. **캡처.**
2. 인터넷이 되면 보고서 › 데이터 조회·추출 › 「표준 구동기 상태」 에서 같은 시간대를 조회. **캡처.**

### 3.9 ⑤ 실노드 증적 만들기 (각 단계 끝마다)
1. 표준노드 탭 맨 아래 ⑤ 「실노드 증적 만들기」 → 노드 선택 → **▶ 지금 상태로 증적 만들기**. 약 5초 뒤 목록에 `realnode-…` 가 생기고 통과/전체가 보입니다.
2. `report.md`·`results.json`·`frames.txt` 를 눌러 노트북에 내려받습니다. report 아래 「수동 증적 항목」 이 캡처 체크리스트입니다.
3. 센서 노드는 3.5(10분) 뒤에, 구동기 노드는 3.6~3.7 명령을 보낸 뒤에 만들어야 전 항목 통과합니다. 실패 항목이 있으면 그 사유가 줄에 적혀 있으니 고친 뒤 다시 만들면 됩니다(옛 묶음은 지우기).
4. 구동기 판정은 **제어판에서 사람이 보낸 명령만** 셉니다(자동화·시험 명령은 이력에 출처만 표기). 반드시 **작동 중에 정지**해야 통과합니다:
   - 온풍기1 📐 시간 지정 ON 20초 → 20초가 끝나기 전에 OFF
   - 측창1 ⏱ 시간 열기 20초 → 끝나기 전에 ■ 정지
   - 측창1 ⏱ 시간 닫기 20초 → 끝나기 전에 ■ 정지

## 4. 실패할 때 보는 곳

| 증상 | 먼저 볼 것 |
|---|---|
| 연결 시험 a) 실패(포트 닫힘) | FTDI 변환기가 꽂혔는지, ① 줄 포트가 `smartfarm-485-std` 인지. 뽑았다 다시 꽂고 「시험 당일 값으로」 → 적용 |
| 연결 시험 d) 만 실패(응답 없음) | 노드 주소, A/B 극성, 종단저항, 노드 24 V, 노드가 9600 8N1 인지 |
| 탐색은 되는데 「스코프 밖」 | 노드가 디폴트맵/레벨1/프로토콜버전 10 이 아님 — 카드의 비고를 캡처, 노드 사양 확인 |
| 제어판 명령 뒤 노드가 안 움직임 | 하우스/센서 탭의 매핑(노드 주소·종류·번호)이 실제 노드와 같은지. 표준노드 탭 ④ 진단에서 FC16 프레임이 나갔는지, 응답이 예외인지 |
| 상태코드가 오류군(1~6) | 노드 자체 오류 — 그대로 기록(표준 표 B 의 정의된 값이라 「정의된 값」 판정) |
| 타임아웃이 계속 늘어남 | 케이블 접촉·거리·종단. 통계는 「통계 초기화」 로 정리 |

## 5. 시험이 끝나면

1. 표준노드 탭 ① 「통신 설정」 → 연결 방식 **시뮬레이터(시험장비)** → 주소 `127.0.0.1:5020` → **적용**.
2. 몇 초 뒤 ③ 에 노드 1(구동기)·노드 2(센서) 카드가 다시 보이면 정상. 30일 데이터 창이 다시 쌓입니다.
3. 노드 24 V 를 끄고 배선을 정리합니다. FTDI 변환기는 그대로 꽂아 둡니다.

## 6. 참고

- 실제 노드로 바꾼 동안 시뮬레이터 노드를 읽지 못해 3번 하우스의 1분 스냅샷이 그 시간만큼 빠집니다. 하루 43분을 넘으면 그날은 30일 창에서 빠지고 다음 날부터 다시 셉니다. 시험 날은 감수하고, 끝나면 5장대로 되돌려 두면 됩니다.
- 자가시험 프로그램(`selftest_sps7466.py`)은 시뮬레이터 전용입니다. 실제 노드 시험의 증적은 이 절차서의 화면 캡처와 ④ 진단 프레임입니다.
- 제어기 MAC 주소(무선): `88:A2:9E:98:DB:18`. 공유기가 기기 등록을 요구하면 이 값을 씁니다.

## 7. 화면별 자동 갱신 / 버튼 정리

| 화면 | 자동·수동 | 설명 |
|---|---|---|
| ① 드라이버 연결 상태(연결됨·포트·예외·타임아웃) | 자동 | 10초마다 갱신 |
| ① 통신 설정 | 수동 | 「시험 당일 값으로」 → 「적용」 두 번 클릭 |
| ① §5.4.1 연결 시험 | 수동 | 주소 입력 → 「▶ 연결 시험 실행」. 결과는 그때 한 번 판정(다시 보려면 다시 실행) |
| ② 노드 찾기 | 수동 | 「탐색」 또는 「자동 스캔」. 노드 주소가 1 이나 2 면 통신 설정 적용 뒤 드라이버가 2초 안에 스스로 다시 탐색해 카드가 뜬다. 다른 주소는 탐색 버튼 |
| ③ 찾은 노드 카드(§5.1.2 시험표·§5.1.3 읽기 표·연결된 디바이스·§5.4.3 변화 이력·§5.4.4 저장 확인) | 자동 | 카드가 뜬 뒤 10초마다 갱신. 남은 작동시간은 1초 단위로 흐른다 |
| ④ 진단(프레임·이벤트) | 처음만 수동 | 「열기」 한 번 → 이후 10초마다 자동 |
| 제어판(시간 지정 ON·시간 열기/닫기·정지) | 수동 | 명령 버튼. 배지·남은시간은 자동 |
| 보고서 › 데이터 조회·추출 | 수동 | 종류·기간 선택 → 「조회」 → 「.csv」 |
| ⑤ 실노드 증적 만들기 | 수동 | 노드 선택 → 「▶ 지금 상태로 증적 만들기」 → 파일 내려받기. 인터넷 없이 됨 |

버튼을 누르는 곳은 여섯 군데뿐이다: 적용 → 연결 시험 실행 → (탐색) → 제어판 명령 → 진단 열기 → 조회/추출. 나머지는 지켜보고 캡처한다.

참고: 통신 설정을 시뮬레이터에서 RS485 로 바꾸면 드라이버가 옛 버스의 탐색 결과를 버리고 새 버스에서 노드 1·2 를 다시 탐색한다(2026-09-16 반영). 실제 노드를 붙였는데 시뮬레이터의 디바이스 목록이 보이면 「탐색」 을 한 번 눌러 준다.
