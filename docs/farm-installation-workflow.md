# SmartFarm 농장 설치 업무 흐름

## 개요

이 문서는 SmartFarm 시스템의 새 농장 등록부터 현장 설치, 사후 관리까지의 전체 업무 흐름을 설명합니다.

- **시스템**: smartgreen.kr (프론트엔드) + api.smartgreen.kr (백엔드)
- **장비**: Raspberry Pi 4 (8GB) + Node-RED + RS-485 릴레이/센서
- **통신**: AWS IoT Core MQTT + Cloudflare Tunnel
- **대상**: 하루 10개 농장씩 점진적 확장, 최대 100개 농장 운영

---

## 1. 사무실 — 농장 계약 및 등록

### 1.1 농장 계약 체결

영업팀이 새 농장과 계약을 체결하고 아래 정보를 관리자에게 전달합니다.

| 항목 | 예시 |
|------|------|
| 농장 이름 | 김철수 농장 |
| 주소 | 전남 장성군 월야면 115번지 |
| 대표자 | 김철수 |
| 연락처 | 010-1234-5678 |
| 이메일 | farm@example.com |
| 하우스 수 | 2동 |
| 형태 | 연동하우스 / 300평 |
| 사업구분 | 환경제어형 |
| 시스템 형태 | 환경제어형 |
| 인터넷 환경 | WiFi (KT/SKT/LGU+) |

### 1.2 시스템 등록 (smartgreen.kr)

관리자가 웹에서 농장을 등록합니다.

**접속**: `https://smartgreen.kr` → 관리자 로그인 → 농장관리 → [+ 농장 등록]

**입력 항목**:
- 농장 ID: 자동 부여 (farm_0005)
- 농장 이름: 김철수 농장
- 형태: 연동하우스 / 300평
- 주소: 전남 장성군 월야면 115번지
- 관리자: 김철수 / 010-1234-5678 / farm@example.com
- 사업구분: 환경제어형
- 시스템 형태: 환경제어형
- 상태: 운전중
- 등록일: 2026-03-27
- 유지보수: 시작일 2026-03-27 / 기간 1년

**저장 시 자동 생성**:
- 농장 ID: `farm_0005`
- API Key: `a7b3c9d2e1f4...` (농장 고유 인증 키)
- 장비 코드: `AF7K2M` (6자리 고유 코드)
- 시스템 계정: 대표자 이름으로 자동 검색/연결

### 1.3 하우스 / 센서 / 장치 사전 설정

농장 등록 후 하우스와 장치를 미리 설정합니다.

**접속**: smartgreen.kr → 해당 농장 선택 → 설정 → 하우스/센서

**1번 하우스 설정**:
| 항목 | 설정값 |
|------|--------|
| 하우스 ID | house_0001 |
| 하우스 이름 | 1번 하우스 |
| 센서 | 온도 (temp_0001), 습도 (humidity_0001) |
| 장치 - 1창 | window1, Waveshare Unit-Id 1, CH0+CH1 (bidir) |
| 장치 - 측창 | side_window1, Waveshare Unit-Id 1, CH2+CH3 (bidir) |
| 장치 - 환풍기 | fan1, Waveshare Unit-Id 1, CH4 (single) |

**2번 하우스 설정** (필요 시):
| 항목 | 설정값 |
|------|--------|
| 하우스 ID | house_0002 |
| 하우스 이름 | 2번 하우스 |
| 센서 | 온도, 습도 |
| 장치 | 1창, 측창 |

> 참고: Modbus 채널 할당은 현장 배선에 따라 설치 후 조정할 수 있습니다.

### 1.4 RPi 장비 준비

사무실에서 설치 키트를 준비합니다.

**SD카드 이미지 굽기** (10분):
1. 표준 SmartFarm RPi 이미지를 PC에 준비
2. balenaEtcher 또는 Raspberry Pi Imager로 새 SD카드에 굽기
3. 이미지에 포함된 것:
   - Raspberry Pi OS
   - Node-RED + 모든 플로우
   - PM2 (node-red, smartfarm-rpi, smartfarm-system)
   - nginx (터치패널 서빙)
   - AWS IoT 인증서
   - 초기 설정 스크립트

**QR 스티커 부착**:
1. 장비 코드(AF7K2M)로 QR 코드 생성
2. QR 스티커를 RPi 본체 뒷면에 부착

## 2. 현장 — 설치 기사 작업

### 2.1 농장 도착 및 현장 확인 (5분)

1. 농장주(김철수)에게 인사 및 설치 안내
2. 제어반 위치 확인 (RPi 설치 장소)
3. 개폐기 모터 배선 확인
4. 전원 콘센트 확인
5. WiFi 수신 상태 확인

### 2.2 하드웨어 설치 (30분)

**RPi 설치**:
1. RPi를 제어반 내부 또는 벽면에 고정 (DIN 레일 마운트 또는 나사 고정)
2. SD카드 삽입

**RS-485 버스 연결**:
```
RPi USB → USB-RS485 어댑터 → RS-485 버스
                                ├── Waveshare 릴레이 8CH (Unit-Id 1)
                                └── 온습도 센서 (Unit-Id 3)
```

3. USB-RS485 어댑터를 RPi USB 포트에 연결
4. RS-485 케이블로 릴레이 모듈 연결 (A+, B-, GND)
5. 같은 RS-485 버스에 온습도 센서 병렬 연결

**릴레이 → 모터 배선**:
```
릴레이 모듈 출력:
  CH0 (NO/COM) → 1창 열기 모터
  CH1 (NO/COM) → 1창 닫기 모터
  CH2 (NO/COM) → 측창 열기 모터
  CH3 (NO/COM) → 측창 닫기 모터
  CH4 (NO/COM) → 환풍기
  CH5~CH7     → 예비
```

6. 릴레이 출력 단자를 개폐기 모터 제어선에 연결
7. 릴레이 모듈 전원 연결 (12V 또는 24V)

**전원 연결**:
8. RPi 전원 어댑터 연결 (5V 3A)
9. RPi 전원 ON (아직 네트워크 미연결 상태)

### 2.3 네트워크 연결 (5분)

**방법 A: 이더넷 (유선)**
1. 공유기 LAN 포트 → RPi 이더넷 포트 연결
2. 자동으로 IP 할당 (DHCP)

**방법 B: WiFi (무선)**
1. RPi에 모니터/키보드 연결 (또는 SD카드에 wpa_supplicant.conf 미리 작성)
2. `sudo raspi-config` → Network → WiFi → SSID/비밀번호 입력
3. 또는 SD카드 boot 파티션에 wpa_supplicant.conf 파일 생성:
```
country=KR
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
network={
    ssid="농장WiFi이름"
    psk="비밀번호"
}
```

**IP 주소 확인**:
- 공유기 관리 페이지에서 확인
- 또는 모니터 연결 후 `hostname -I`
- 또는 핸드폰 네트워크 스캔 앱 사용

### 2.4 장비 초기 설정 (3분)

1. 핸드폰(또는 노트북) 브라우저에서 RPi IP 접속:
   ```

   ```

2. 초기 설정 페이지가 표시됨:

6. 설정 완료 확인

### 2.5 동작 확인 테스트 (5분)

**센서 확인**:
1. 핸드폰에서 `smartgreen.kr` 접속 → 로그인
2. 김철수 농장 선택 → 대시보드
3. 60초 대기 → 센서 데이터(온도, 습도) 수신 확인
4. "수집 대기" → "정상" 으로 변경 확인

**제어 확인**:
5. 제어 탭 → 1번 하우스 선택
6. 1창 → [▲ 열기] 클릭 → 모터 동작 확인 (창문 열림)
7. 1창 → [■ 정지] 클릭 → 모터 정지 확인
8. 측창 → [▲ 열기] → 확인 → [■ 정지]
9. 환풍기 → [ON] → 확인 → [OFF]

**릴레이 전체 테스트** (선택):
10. 설정 → 시스템 → Modbus → 릴레이 모듈 → [채널 테스트]
11. CH0~CH7 모두 OK 확인

**비상정지 테스트**:
12. [⛔ 비상정지] 클릭 → 모든 릴레이 OFF 확인

### 2.6 설치 완료 처리 (2분)

1. smartgreen.kr → 농장관리 → 김철수 농장
2. 상태: "운전중" 확인
3. 접속: "🟢 온라인" 확인
4. 제어반 사진 촬영 (설치 기록용)
5. 농장주에게 간단한 사용 안내:
   - `smartgreen.kr`에서 모니터링 가능
   - 비상 시 비상정지 버튼 사용
   - 문제 발생 시 사무실 연락
6. 사무실에 설치 완료 보고 (카톡/전화)

## 3. 사무실 — 사후 관리

### 3.1 설치 확인

관리자가 웹에서 설치 완료를 확인합니다.

```
smartgreen.kr → 농장관리 → 농장 목록

| No | 농장명      | 상태   | 접속    | 장비코드 |
|----|-----------|-------|--------|---------|
| 5  | 김철수 농장 | 운전중 | 🟢 온라인 | AF7K2M  |
```

확인 사항:
- 상태: 운전중
- 접속: 온라인
- 센서 데이터 수신 중
- 마지막 통신 시각 정상

### 3.2 일상 모니터링 (매일)

**매일 아침 확인 사항**:

1. 농장 목록에서 🔴 오프라인 농장 체크
   - 오프라인 → 해당 농장 연락 → 네트워크/전원 확인
2. 알림 탭 확인
   - 센서 이상 알림 (온도 초과 등)
   - 장비 고장 알림 (Modbus 응답 없음)
   - 오프라인 알림 (5분 이상 미접속)
3. 유지보수 만료 임박 농장 확인
   - 30일 전 알림 → 계약 연장 안내

### 3.3 원격 트러블슈팅

문제 발생 시 사무실에서 원격으로 대응합니다.

**센서 데이터 안 올 때**:
1. smartgreen.kr → 해당 농장 대시보드 확인
2. "수집 대기" → 서버 탭 → RPi 상태 확인
3. 설정 → 시스템 관리 → Node-RED 재시작 (원격)

**릴레이 동작 안 할 때**:
1. 설정 → Modbus → 릴레이 모듈 → [테스트]
2. "연결됨" → 채널 테스트로 개별 채널 확인
3. "미연결" → 현장 방문 필요 (RS-485 배선 확인)

**RPi 응답 없을 때**:
1. 농장주에게 전원 확인 요청 (전원 OFF→ON)
2. 5분 후 온라인 복귀 확인
3. 미복귀 시 현장 방문

### 3.4 펌웨어 업데이트

Node-RED 플로우 업데이트가 필요한 경우:

1. 새 표준 이미지에 업데이트 반영
2. 기존 농장: 원격으로 Node-RED 플로우 업데이트 (추후 OTA 구현 예정)
3. 신규 농장: 새 이미지로 자동 적용

## 6. 주의사항

### 하드웨어
- RS-485 배선 극성 확인 (A+, B- 반대 연결 시 통신 불가)
- USB-RS485 어댑터는 CH340 칩셋 권장 (RPi 호환성)
- Modbus Unit-Id 충돌 주의: 릴레이(1), 센서(3) 다르게 설정
- 릴레이 전원과 RPi 전원 분리 (노이즈 방지)

### 네트워크
- 농장 WiFi가 안정적인지 사전 확인
- WiFi 신호 약하면 중계기 또는 이더넷 사용
- 인터넷 속도: 1Mbps 이상이면 충분

### 보안
- 농장별 API Key 사용 (공유 금지)
- RPi SSH 비밀번호 변경 (기본값 사용 금지)
- AWS IoT 인증서 농장별 분리 (권장)

### 절대 금지
- RPi SD카드를 다른 농장의 것과 바꿔 사용하지 않기
- Node-RED 에디터에서 함부로 플로우 수정하지 않기
- RS-485 버스에 Modbus 클라이언트 2개 이상 연결하지 않기
