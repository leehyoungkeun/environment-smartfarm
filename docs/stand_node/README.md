# 우노로 만든 KS X 3267 표준 노드 (시험용)

Arduino UNO + MAX485 로 만든 디폴트 레지스터맵 노드 2종. 제어기(ks3267d)의 실 노드 교차 시험용이다.
`standard_node.txt` 는 처음 받은 원본(주소 규칙이 KS−1 이라 그대로 쓰면 제어기가 못 찾는다 — 2026-09-19 검토).

| 스케치 | 노드 | 제품타입·채널 | 디바이스 | 지원 FC |
|---|---|---|---|---|
| `ksx3267_sensor_node_uno/` | 센서 노드 | 1 · 30 | 온도1(#1, 코드 1)·습도1(#4, 코드 2) 모의값(천천히 흔들림) | 03/04 |
| `ksx3267_actuator_node_uno/` | 구동기 노드 | 2 · 24 | 스위치 1~4(코드 102)·개폐기 1~2(코드 112), 나머지 미부착 0 | 03/04/06/16 |

9600 8N1. 슬레이브 주소는 **구동기 1 · 센서 2** — 시뮬레이터(구동기 unit 1, 센서 unit 2)·3번 하우스 매핑(온풍기1/측창1 = U1, 온도1 = U2 #1)·드라이버 자동 탐색(--units 1,2)과 같다. 우노 두 대에 하나씩 올려 같은 버스에 함께 붙인다(주소가 같은 노드 둘은 둘 다 안 잡힌다).

## 주소 규칙 (핵심)

전문(PDU) 주소 = KS 레지스터 번호 **그대로**. KS X 3267:2022 4.3.4.1 예시가 "레지스터 100~103 읽기" 요청의 Starting Address 를 0x0064 = 100 으로 보여 준다. 제어기 드라이버도 이 규칙(노드정보 (1,8)·디바이스코드 (101,n)·센서블록 (202,91)·구동기블록 (201,98)·명령 FC16 503+4(k−1)/567+4(j−1)).

## 배선

| MAX485 | 우노 | | MAX485 | 제어기 FTDI 변환기 |
|---|---|---|---|---|
| VCC | 5V | | A | A (D+) |
| GND | GND | | B | B (D−) |
| RO | D10 | | GND | GND |
| DI | D11 | | | |
| DE+RE (묶음) | D4 | | | |

CH340 변환기(`/dev/smartfarm-485`, 릴레이·온습도계 버스)에는 절대 연결하지 않는다. 우노 USB 는 노트북(전원 + 디버그 시리얼 115200).

구동기 노드 출력 핀(LED·릴레이 모듈로 동작 확인): 스위치1~4 → D5·D6·D7·D8(스위치1 은 D13 보드 LED 겸), 개폐기1 열림/닫힘 → D2/D3, 개폐기2 → D12/A1.

## 올리기·확인

1. Arduino IDE 2 → 파일 › 열기 → 스케치 폴더의 `.ino` → 보드 Arduino Uno, 포트는 CH340 호환 보드가 잡힌 COM(이 PC 는 COM41; COM5~7 은 블루투스 가상 포트) → 업로드.
2. 시리얼 모니터 115200: 센서는 `temp=… humi=…` 매초, 구동기는 `ready, ID 1, switches 4, openers 2`. `DEBUG_RX 1` 이면 받은 프레임이 `RX ok len=8: 01 03 00 01 00 08 …` 로 찍힌다(배선 확인 뒤 0 으로).
3. 제어기 표준노드 탭: ① 「시험 당일 값으로」→적용 → 「§5.4.1 연결 시험」 unit 1 → ② 탐색 1 → ③ 카드 확인 → ⑤ 「실노드 증적 만들기」.
4. 구동기 노드는 3번 하우스 매핑(온풍기1 = U1 스위치1, 측창1 = U1 개폐기1, 30 s)과 그대로 맞으므로 제어판 › 3번 하우스에서 「시간 지정 ON」·「시간 열기/닫기」·정지를 보내면 D13/D2/D3 이 켜지고, 시리얼 모니터에 `ACT #1 op=202 opid=… t=20 -> status=201`, 만료 시 `DONE #1` 이 찍힌다.

## 구동기 노드 의미론 (본문 6.1.4 / 6.3.3 / 6.3.4, 시뮬레이터 `tools/ks3267-sim/node.py` 와 동일)

- 명령 블록(cmd, opid, time lo/hi)을 쓴 뒤 **OPID 가 바뀐 시점**에만 활성화. OPID 0 이거나 직전과 같으면 무시(§5.3.4).
- 스위치: 0 → READY, 201 → ON(무한), 202 → ON + 남은시간 → 만료 READY. 개폐기: 0 → READY, 301/302 → OPENING/CLOSING 30 s, 303/304 → 지정 시간.
- 203·305·306(레벨 2)·미부착 디바이스·시간 0 인 TIMED → 예외 0x03, 레지스터 아무것도 안 바뀜(§5.3.1/5.3.3).
- 상태 블록 OPID 는 실행 중 명령의 OPID, READY 면 0(표 16). 남은시간 uint32 하위 워드 먼저.

컴파일 확인(2026-09-19, arduino-cli, Uno): 센서 6,958 B / RAM 1,261 B · 구동기 6,688 B / RAM 1,119 B.
