주요 기능

🔌

기존 수동 제어반에 연결 — 그대로 원격 제어

농가의 수동 제어반·마그네트·컨트롤박스 ON/OFF 신호선에 연결만 하면 스마트폰 원격 제어·자동화·데이터 기록을 그대로 얹을 수 있습니다. 기존 설비 교체 없이 도입하므로 초기 비용이 크게 절감되며, 수동 스위치는 그대로 살아있어 비상 시 직접 조작이 가능합니다.

📊

실시간 환경 측정

내부·외부 환경을 1분 주기로 측정. 게이지 색으로 위험·주의·정상을 한눈에.

⚙️

자동 제어 규칙

센서 기반 / 시간대별 / 사용자 정의 규칙. 조건이 맞으면 천창·측창·환기팬이 자동 동작.

💧

양액 자동 제어

시나리오별 EC·pH 목표 자동 조성. 14구역 관수 밸브 순차 공급. 자동·수동·직접 3모드.

🔒

안전 인터록

EC·pH 한계 이탈, 탱크 잔량 부족, 사이클 시간 초과 시 자동 정지하고 알림 발송.

📓

영농일지·자재 관리

일지·수확·자재 입출고를 한곳에. 농약 사용은 PLS 대응 필수 항목으로 자동 입력 유도.

📈

보고서 출력

환경·수확·자재·알림 이력을 기간별로 PDF·엑셀 출력. 출하 거래처·기술센터 제출용.

🤖

AI 도우미

잎·열매 사진으로 병해충 진단. 재배 상담·이상값 분석을 한국어 대화로.

📶

오프라인 자동 전환

인터넷이 끊겨도 농장 와이파이 안에서 로컬 제어. 복구 시 클라우드 자동 동기화.
