# 자체 시험 성적서 — 스마트그린 통합제어기 (KS X 3267 / SPS-X KOAT-0004-7466 / KOAT 116·117)

작성 2026-09-14. 흩어진 증적 폴더와 운영 DB 실측을 한 장으로 모았다. 각 행의 증적 폴더에 `report.md`(단계별 판정)·`results.json`·`frames.txt`(TX/RX hex)가 있다.

- **시험대상장비**: 스마트그린 통합제어기 — Raspberry Pi 5 + Node-RED + `ks3267d` 드라이버 + 웹/키오스크 화면

- **시험 입구**: 화면과 같은 로컬 제어 REST(`POST /api/control/local`) → `execute_control` → 표준 명령 조립 → 드라이버 FC16

## 4. 한계 — 본시험 전에 채울 것

- **시험장비가 시뮬레이터다.** 실 노드 1대로 같은 스크립트를 다시 돌려야 한다(`ks3267d --port /dev/smartfarm-485-std`).
- **연결 해제를 응답 차단으로 재현했다.** 실물 시험은 M12 커넥터를 물리적으로 뽑는다. 복귀 3.0초는 시뮬레이터의 타임아웃(3초)과 맞물린 값이고, 실선에서는 드라이버 응답 대기 시간 + 폴링 주기(2초)로 정해진다. 기준 120초와는 여유가 크다.
- **화면 증적은 수동이다.** 관제 방식(키오스크·웹·모바일)마다 표준노드 탭과 제어판 배지 캡처가 필요하다. 신고 개수는 시험기관 문의 3번 답 후 확정.
- **해석 겹침 1건.** READY 상태의 OPID(명령 OPID 유지 vs 0) — 시뮬레이터는 0, 자가시험은 둘 다 통과로 기록. 시험기관 문의 7번.
