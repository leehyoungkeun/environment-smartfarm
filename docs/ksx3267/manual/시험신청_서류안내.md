# 시험 신청 서류 — 무엇을 어떻게 내는가 (2026-09-28)

받은 양식 두 가지를 정리했다. **신청서는 두 장을 따로 낸다.**

| 신청서 | 무엇을 보나 | 처리기간 |
|---|---|---|
| **농업기계(성능)시험 신청서** | KOAT 검정기준 116 「통합제어기」 — 수집 주기, 1/7/30일 조회, 연결 해제·재연결, 관제 방식별 동작 | 30일 |
| **농업기계(국가표준)시험 신청서** | KS X 3267:2022 적합성 — SPS-X KOAT-0004-7466 §5.4/§5.5 | 60일 |

두 시험을 같이 받으려면 **신청서를 각각 작성해 각각 제출**한다(안내자료 2번 항목에 노란색으로 강조되어 있다).

서류를 완성하려면 **답이 있어야 채워지는 칸**이 있다. `koat-inquiry.md` 문의서가 9/14부터 발송 대기 중이다.

| 3. 관제 방식 신고 개수 | 규격설명서 5-가 표 · 시험 반복 횟수 |
| 5. 시험장비(노드) 지참 여부 | CO₂ ○ 선언 가능 여부 |
