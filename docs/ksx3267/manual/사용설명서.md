# 스마트그린 통합제어기 — KS X 3267 표준 노드 사용설명서

버전 1.0 (2026-08-30). KOAT 검정기준 116/117 「통합제어기」 조작 난이도 시험은 이 설명서대로 시험자가 조작한다.
대상: 농장 관리자·설치 기사. 화면은 웹(smartgreen.kr)·모바일 앱(PWA)·현장 키오스크가 같다.

## 1. 개요
- 통합제어기(RPi)는 **두 개의 RS-485 포트**를 가진다.
  - 포트 1 `/dev/smartfarm-485`: 자체 릴레이(Waveshare)·온습도(XY-MD02) — 기존 장치
  - 포트 2 `/dev/smartfarm-485-std`: **KS X 3267:2022 표준 센서/구동기 노드** (Modbus RTU 9600 8N1, 제어기 = 마스터)
- 표준 노드는 **디폴트 레지스터맵·레벨 1**(스위치 ON/OFF/시간제한 ON, 개폐기 열기/닫기/정지/시간제한) 을 지원한다. 레벨 2 명령과 자동등록(KS X 3286) 노드는 지원하지 않는다.
- 표준 노드용 드라이버(`ks3267d`)가 노드를 2초마다 폴링하고, 상태를 화면과 서버에 반영한다.

## 2. 배선
| 핀 (M12 4핀 A-코드) | 신호 | 색 |
|---|---|---|
| 1 | +24 VDC (노드 급전) | 적 |
| 2 | RS485-A | 녹 |
| 3 | RS485-B | 백 |
| 4 | GND | 흑 |

- 버스 양 끝에 120 Ω 종단. 노드 주소(1~247)는 노드 제조사 설정을 따른다. 한 버스에 같은 주소가 둘이면 안 된다.
- 전원을 넣기 전 A/B 를 확인한다. 뒤바뀌면 "응답 없음"으로 보인다.

## 3. 노드 연결 확인 (설정 › 📐 표준노드)
1. 상단 배지가 **드라이버 연결됨** 인지 확인한다. "드라이버 없음"이면 현장 기사에게 연락 (RPi `pm2 ks3267d`).
2. **노드 주소**에 노드의 슬레이브 주소를 넣고 **탐색**을 누른다.
3. 노드 카드가 나타난다: 종류(센서/구동기), 디폴트맵·레벨1 배지, 프로토콜 버전(10), 채널 수, 시리얼, 디바이스 표(번호·코드·현재 상태·우리 장치 매핑).
   - "스코프 밖" 배지: 자동등록 노드 또는 복합 노드 — 이 제어기로는 쓸 수 없다.
   - 표의 "미지원": 레벨 2 디바이스 — 표시만 되고 제어할 수 없다.
4. 응답이 없으면: 주소·A/B·종단·24V 를 순서대로 확인한다. 하단 **진단**을 펼치면 보낸/받은 프레임(hex)과 타임아웃 횟수가 보인다.

## 4. 장치 매핑 (설정 › 🏠 하우스/센서)
### 4.1 구동기
1. 하우스 선택 → 장치 목록에서 장치를 펼친다 (없으면 "장치 추가": 이름·종류 선택).
2. 우측 상단 프로토콜을 **표준 노드 (KS X 3267)** 로 바꾼다.
3. 노드 주소(unit) · 디바이스 종류(스위치/개폐기) · 번호(스위치 1~16, 개폐기 1~8) 를 표준노드 탭의 탐색 표와 같게 넣는다. 범위를 벗어나면 빨간 안내가 뜬다.
4. **저장**. 목록에 `📐 표준 U1 스위치3` 배지가 붙는다.
### 4.2 센서
1. 센서를 펼치고 **표준 노드에 매핑**을 누른다.
2. 노드 주소와 센서 순번(디폴트맵: 1 온도, 4 습도, 13 CO₂ …)을 넣고 **저장**.
3. 값은 다음 수집 주기(1분)부터 대시보드·차트·알림에 자체 센서와 똑같이 들어간다. 노드가 3분 넘게 응답하지 않으면 값은 **비어 있다** (지어내지 않는다).
### 4.3 확인
표준노드 탭에서 해당 디바이스 행의 "우리 장치" 칸에 하우스/장치명이 보인다. 같은 디바이스에 둘 이상 매핑되면 상단에 경고가 뜬다.

## 5. 제어 (🎛️ 환경제어)
- 스위치: **ON / OFF**. 예약(⏱)으로 N 초 뒤 자동 OFF 를 걸면 노드에 시간제한 ON(202) 으로 전달된다.
- 개폐기: **열기 / 정지 / 닫기**. 동작 시간을 주면 시간제한 열기/닫기(303/304).
- 카드의 **📐 배지**가 노드가 보고한 상태를 보여 준다: `켜짐 18s`(남은 시간), `열리는 중`, `READY`, `수동 조작중`, `오류`, `노드 응답 없음`.
- 명령이 거부되면(노드 오류·버스 단선) 카드가 빨갛게 되고 제어 이력에 실패로 남는다.
- 자동화 규칙(설정 › 자동화규칙)은 표준 장치에도 그대로 적용된다.

## 6. 데이터 조회·추출 (📄 보고서 › 데이터 조회·추출)
1. 종류: **센서 관측치 / 구동기 제어 이력 / 표준 구동기 상태**.
2. 하우스, 조회기간(**1일 / 7일 / 30일** / 직접 입력), 항목(선택 없음 = 전체).
3. **조회**: 1분 단위 행이 표로 나온다(200행/쪽). 우측에 행 수·소요 시간(3분 이내) 표시.
4. **추출**: `.csv` `.txt` 는 서버에 저장된 원본 그대로 파일로, `.xlsx` 는 조회한 표를 엑셀로 저장.
   - 센서 파일: `timestamp, 센서ID…` (1분 1행, 결측은 빈 칸)
   - 구동기 상태 파일: `timestamp, house_id, device_id, unit, kind, n, status, status_name, remain_sec, opid`
5. 대시보드 차트는 1시간~30일(30일은 1시간 단위)로 시각화한다.

## 7. 점검·장애
| 증상 | 확인 |
|---|---|
| 표준노드 탭 "드라이버 없음" | RPi 전원·`pm2 ks3267d`. 자체 릴레이·센서는 별도 포트라 계속 동작 |
| 노드 카드 "응답 없음" | 배선 A/B·종단·24V·주소. 진단의 타임아웃 카운터 증가 |
| 📐 배지 "오류/전압 이상/퓨즈 이상" | 노드 자체 상태코드(1~6). 노드 전원·퓨즈 점검 |
| 📐 배지 "수동 조작중" | 노드 현장 스위치가 수동 위치. 원격 명령은 무시된다 |
| 센서 값이 비어 있음 | 노드 3분 이상 무응답 또는 센서 상태 "점검/보정/교체 필요"(101~103) — 표준노드 탭 표에서 확인 |
| 전원 차단 후 복구 | RPi 재기동 시 드라이버·화면이 자동 복귀. 저장 데이터는 서버·로컬 SQLite 에 유지되며 조회·추출 가능 |

## 8. 사양 요약
- 통신: RS-485 Modbus RTU, 9600 bps 8N1, 기능코드 0x03 읽기 / 0x10 쓰기, 프로토콜 버전 10
- 지원: 센서 노드(디폴트맵 30채널), 구동기 노드(스위치 16 + 개폐기 8, 레벨 1)
- 상태 저장: 센서 1분, 구동기 상태 1분 스냅샷, 제어 이력 건별. 조회기간 최대 31일/회
