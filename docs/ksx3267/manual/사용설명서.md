# 스마트그린 통합제어기 — KS X 3267 표준 노드 사용설명서

버전 1.1 (2026-10-06). KOAT 검정기준 116/117 「통합제어기」 조작 난이도 시험은 이 설명서대로 시험자가 조작한다.
대상: 농장 관리자·설치 기사. 화면은 웹(smartgreen.kr)·모바일 앱(PWA)·현장 키오스크가 같다.

## 1. 개요
- 통합제어기(RPi)는 **두 개의 RS-485 포트**를 가진다.
  - 포트 1 `/dev/smartfarm-485`: 자체 릴레이(Waveshare)·온습도(XY-MD02) — 기존 장치
  - 포트 2 `/dev/smartfarm-485-std`: **KS X 3267:2022 표준 센서/구동기 노드** (Modbus RTU 9600 8N1, 제어기 = 마스터)
- 표준 노드는 **디폴트 레지스터맵·레벨 1**(스위치 ON/OFF/시간제한 ON, 개폐기 열기/닫기/정지/시간제한) 을 지원한다. 레벨 2 명령과 자동등록(KS X 3286) 노드는 지원하지 않는다.
- 표준 노드용 드라이버(`ks3267d`)가 노드를 2초마다 폴링하고, 상태를 화면과 서버에 반영한다.

## 2. 배선
| 핀 (M12 4핀 A-코드) | 신호 | 색 |
|---|---|---|
| 1 | +24 VDC (노드 급전) | 적 |
| 2 | RS485-A | 녹 |
| 3 | RS485-B | 백 |
| 4 | GND | 흑 |

- 버스 양 끝에 120 Ω 종단. 노드 주소(1~247)는 노드 제조사 설정을 따른다. 한 버스에 같은 주소가 둘이면 안 된다.
- 전원을 넣기 전 A/B 를 확인한다. 뒤바뀌면 "응답 없음"으로 보인다.

## 3. 노드 연결 확인 (설정 › 📐 표준노드)

### 3.1 통신 설정 (①)
- **연결 방식**(RS485 / 시뮬레이터), **포트**, **통신 속도**(표준 9600), **응답 대기**를 화면에서 바꾼다. SSH 가 필요 없다.
- **「시험 당일 값으로」** 를 누르면 RS485 · 표준 노드 포트 · 9600 으로 한 번에 채워진다. 그 뒤 **적용**.
- 자체 장치 버스(`/dev/smartfarm-485`)는 고를 수 없다 — 기존 릴레이·센서 제어가 멈추지 않게 막아 두었다.
- **§5.4.1 연결 시험** 버튼이 a)~d) 를 한 번에 판정한다.

### 3.2 저장 주기 (①)
- 표준 노드 값을 몇 초마다 한 줄로 남길지 정한다. 프리셋 10초·30초·**1분(표준)**·5분·10분, 또는 10~3600초 직접 입력.
- **검정 중에는 60초를 유지한다** (KOAT 116 「1분 단위 30일」). 60초가 아니면 화면에 경고가 뜬다.
- 노드를 읽는 것은 이 값과 무관하게 **2초마다**다. 저장만 이 주기로 한 줄 남긴다. 제어기를 재시작해도 설정이 유지된다.
- 이 설정은 **제어기 로컬 저장(SQLite)** 에 적용된다. 서버 저장은 1분 주기로 따로 보낸다.

### 3.3 노드 찾기 (②)
1. 상단 배지가 **드라이버 연결됨** 인지 확인한다. "드라이버 없음"이면 현장 기사에게 연락 (RPi `pm2 ks3267d`).
2. 주소를 알면 **A. 주소 하나 탐색**, 모르면 **B. 범위 자동 스캔**(보통 1~16, 300 ms)을 누른다.
3. 노드 카드가 나타난다: 종류(센서/구동기), 디폴트맵·레벨1 배지, 프로토콜 버전(10), 채널 수, 시리얼, 디바이스 표(번호·코드·현재 상태·우리 장치 매핑).
   - "스코프 밖" 배지: 자동등록 노드 또는 복합 노드 — 이 제어기로는 쓸 수 없다.
   - 표의 "미지원": 레벨 2 디바이스 — 표시만 되고 제어할 수 없다.
4. 응답이 없으면: 주소·A/B·종단·24V 를 순서대로 확인한다. ④ **진단**을 펼치면 보낸/받은 프레임(hex)과 타임아웃 횟수가 보인다.
5. 노드 카드 안에서 바로 확인되는 것 — **노드 기본정보 시험표**(§5.1.2), **노드 데이터 읽기 시험표**(§5.1.3, 관측치·상태코드·**읽은 레지스터 번지**, 10초마다 갱신), **관측 변화 이력**(§5.4.3), **데이터 저장 확인**(서버)·**제어기 로컬 저장**(SQLite), **읽는 레지스터 주소**, **연결된 디바이스**.

### 3.4 센서를 떼거나 더 붙였을 때
제어기가 **1분마다 노드 구성을 다시 확인한다.** 센서를 떼면 60초 안에 그 자리를 읽지도 저장하지도 않고,
다시 꽂으면 그 자리부터 다시 읽는다. 사람이 다시 탐색을 누를 필요가 없다.

### 3.5 실노드 증적 만들기 (⑤)
버튼 하나로 지금 읽히는 것을 §5.4 / §5.5 순서로 판정해 `report.md` · `results.json` · `frames.txt` 를 제어기에 남긴다(약 5초).
목록에서 파일별로 내려받을 수 있다. 시험 화면 캡처의 뒷받침 자료다.

### 3.6 네트워크 설정 (현장 키오스크 전용)
설정 › **네트워크** 에서 키보드 없이 WiFi 를 바꿀 수 있다. 저장된 망은 비밀번호를 다시 묻지 않는다.

## 4. 장치 매핑 (설정 › 🏠 하우스/센서)
### 4.1 구동기
1. 하우스 선택 → 장치 목록에서 장치를 펼친다 (없으면 "장치 추가": 이름·종류 선택).
2. 우측 상단 프로토콜을 **표준 노드 (KS X 3267)** 로 바꾼다.
3. 노드 주소(unit) · 디바이스 종류(스위치/개폐기) · 번호(스위치 1~16, 개폐기 1~8) 를 표준노드 탭의 탐색 표와 같게 넣는다. 범위를 벗어나면 빨간 안내가 뜬다.
4. **저장**. 목록에 `📐 표준 U1 스위치3` 배지가 붙는다.
### 4.2 센서
1. 센서를 펼치고 **표준 노드에 매핑**을 누른다.
2. 노드 주소와 센서 순번(디폴트맵: 1 온도, 4 습도, 13 CO₂ …)을 넣고 **저장**.
3. 값은 다음 수집 주기(1분)부터 대시보드·차트·알림에 자체 센서와 똑같이 들어간다. 노드가 3분 넘게 응답하지 않으면 값은 **비어 있다** (지어내지 않는다).
### 4.3 확인
표준노드 탭에서 해당 디바이스 행의 "우리 장치" 칸에 하우스/장치명이 보인다. 같은 디바이스에 둘 이상 매핑되면 상단에 경고가 뜬다.

## 5. 제어 (🎛️ 환경제어)
- 스위치: **ON / OFF**. 예약(⏱)으로 N 초 뒤 자동 OFF 를 걸면 노드에 시간제한 ON(202) 으로 전달된다.
- 개폐기: **열기 / 정지 / 닫기**. 동작 시간을 주면 시간제한 열기/닫기(303/304).
- 카드의 **📐 배지**가 노드가 보고한 상태를 보여 준다: `켜짐 18s`(남은 시간), `열리는 중`, `READY`, `수동 조작중`, `오류`, `노드 응답 없음`.
- 명령이 거부되면(노드 오류·버스 단선) 카드가 빨갛게 되고 제어 이력에 실패로 남는다.
- 자동화 규칙(설정 › 자동화규칙)은 표준 장치에도 그대로 적용된다.

## 6. 데이터 조회·추출·시각화 (📄 보고서)
보고서 안에 **「데이터 조회·추출」** 과 **「데이터 시각화」** 두 탭이 있다.

### 6.1 데이터 조회·추출
1. 종류: **센서 관측치 / 구동기 제어 이력 / 표준 구동기 상태**.
2. 하우스, 조회기간(**1일 / 7일 / 30일** / 직접 입력), 항목(선택 없음 = 전체). 고른 항목만 아래에 나온다.
3. **조회**: 센서·장치마다 **카드 하나**가 생기고, 위쪽 탭으로 오간다. 카드 안은 50행씩 쪽을 넘긴다.
   우측에 행 수·소요 시간(3분 이내) 표시.
4. **📈 그래프 보기**: 표 아래에 그래프가 함께 나온다(표가 사라지지 않는다).
   - 센서는 **값**을 곡선으로.
   - 구동기는 값이 없으므로 **상태코드 · 남은시간 · OPID** 중에서 「그릴 항목」으로 고른다.
     상태는 바뀐 시점까지 유지되는 값이라 **계단**으로 그린다.
   - 점이 많으면 균등 간격으로 솎아 그린다(표·파일은 전체 그대로).
5. **파일로 저장**: 위쪽 `CSV` `TXT` `XLSX` 는 조회한 전체를, 카드의 **「이 센서만」 `CSV` `XLSX`** 는 그 센서(장치)만 저장한다.
   - 센서 파일: `timestamp, 센서ID…` (1분 1행, 결측은 빈 칸)
   - 구동기 상태 파일: `timestamp, house_id, device_id, unit, kind, n, status, status_name, remain_sec, opid`

### 6.2 데이터 시각화
- 조회·추출과 같은 구조(항목 카드 → 센서별 탭)로, 기간 **1일 / 7일 / 30일** 을 고른다.
- **집계 단위**를 1 ~ 60분 사이 아무 값으로 정한다(프리셋 1·5·10·15·30·60분 또는 직접 입력).
- 센서마다 최저·평균·최고와 그래프를 보여 준다.

### 6.3 인터넷이 없을 때
표준노드 탭의 **「제어기 로컬 저장」** 카드가 제어기 안(SQLite)에 쌓인 1분 행을 그대로 보여 준다.
서버·인터넷 없이도 저장과 조회를 그 자리에서 확인할 수 있다.

| 센서를 다시 꽂았는데 안 읽힘 | 같다 — 최대 1분. 그래도 안 되면 주소·A/B·종단 확인 |

## 8. 사양 요약
- 통신: RS-485 Modbus RTU, 9600 bps 8N1, 기능코드 0x03 읽기 / 0x10 쓰기, 프로토콜 버전 10
- 지원: 센서 노드(디폴트맵 30채널), 구동기 노드(스위치 16 + 개폐기 8, 레벨 1)
- 폴링(읽기): 2초. **저장 주기: 기본 1분**(화면에서 10~3600초 조정, 검정 기준 1분), 구동기 상태 1분 스냅샷, 제어 이력 건별
- 저장 위치: 서버 + **제어기 로컬 SQLite**(인터넷 없이 조회·추출 가능). 조회기간 최대 31일/회
- 시각화: 집계 단위 1~60분, 기간 1/7/30일

## 9. 안전 사용 요령
- **감전 주의**: 배선·단자 작업은 반드시 24 VDC 전원을 차단한 뒤 한다. 통전 중 단자에 손대지 않는다.
- **극성·종단**: RS-485 A(녹)/B(백) 극성을 지키고 버스 양 끝에 120 Ω 종단을 단다. 뒤바뀌면 "응답 없음"으로 보인다.
- **설치 환경**: 제어기(본체)는 실내 또는 방수·방진 제어함 안에 설치한다. 직사광·고온·결로를 피하고, 제어함이 밀폐면 환기(또는 쿨러)를 둔다. 본체는 자연 방열이므로 함체 온도가 높으면 성능이 제한될 수 있다.
- **구동기 동작 주의**: 측창·개폐기 등 구동기가 자동·원격으로 움직일 수 있다. 정비·청소 시 반드시 해당 구동기를 **정지**시키고, 동작 구간에 사람·장애물이 없는지 확인한다(끼임 주의).
- **과전압·낙뢰**: 전원부에 서지 보호를 두고, 뇌우 시 장시간 정비를 피한다.
- **임의 개조 금지**: 본체·노드·배선을 임의로 개조·분해하지 않는다. 인증·보증이 무효가 될 수 있다.

## 10. 점검·정비·보관
- **일상 점검(사용자)**: 화면의 📐 상태 배지가 READY/정상인지, 노드가 "응답 없음"이 아닌지, 종단·전원 표시등을 육안 확인한다.
- **정기 정비(6개월 권장)**: 전원 차단 후 단자 조임 상태·접점 부식·퓨즈를 점검하고, 제어함 내부 먼지 제거·환기구 청소를 한다. RS-485 배선 피복 손상을 확인한다.
- **소프트웨어 갱신**: 제어기 소프트웨어·드라이버는 원격으로 갱신·복구된다(사용자 조치 불필요). 이상 시 사후관리업소에 연락한다.
- **장기 보관**: 전원을 차단하고 건조한 상온(권장 −10 ~ 40 ℃, 결로 없음)에 보관한다. 재사용 시 §2 배선·§3 노드 연결 확인부터 다시 수행한다.
